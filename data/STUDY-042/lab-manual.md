# Laboratory Services Manual STUDY-042 (Version 1.0)
**Central Laboratory:** Global Clinical Diagnostics Laboratories  
**Effective Date:** January 01, 2024  

## 1. Laboratory Reference Ranges & Units
Central laboratory tests are analyzed on Roche Cobas 8000 automated platforms.
All liver transaminases (ALT, AST, ALP) are reported in International Units per Liter (U/L).

| Analyte | Test Code | Reported Unit | Normal Low | Normal High |
| :--- | :--- | :--- | :--- | :--- |
| Alanine Aminotransferase | ALT | U/L | 0 | 45 |
| Aspartate Aminotransferase | AST | U/L | 0 | 40 |
| Total Bilirubin | TBIL | mg/dL | 0.2 | 1.2 |
| Alkaline Phosphatase | ALP | U/L | 30 | 120 |
| Serum Creatinine | CREAT | mg/dL | 0.6 | 1.2 |
| Hemoglobin A1c | HBA1C | % | 4.0 | 6.0 |
| Fasting Plasma Glucose | GLUC | mg/dL | 70 | 99 |

## 2. Local Laboratory Conversions
Where emergency or site-specific local laboratories report enzymatic activity in SI microkatals (µkat/L):
- **Conversion Factor:** 1 µkat/L = 60 U/L
- Example: 0.50 µkat/L = 30 U/L.

## 3. Special Reporting Values
- Quantitative values below the assay lower limit of quantification (LLOQ) must be explicitly reported with the '<' prefix (e.g. `<5 U/L`).
- Samples not processed or hemolyzed must be designated as 'ND' (Not Done).
- Do not impute numerical zero for non-quantifiable or missing samples.
